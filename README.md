# **Welcome to my Github page!**

### This repository extends Dr. Marilyn Raphael's Zonal Wave 3 (ZW3) index through the present day (~2025). Note that all scripts can be used regressively for reconstruction analysis. 

#### For additional information on ZW3 as an atmospheric feature and/or the index calculation, please refer to Raphael's (2004) original publication, which can be found here: https://doi.org/10.1029/2004GL020365
